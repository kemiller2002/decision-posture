Guided quick assessment

Try Clarity in 3 to 5 minutes.

Start with the smallest version that shows the value: the claim, the evidence, the assumptions, the owner, and what would change your mind. Deeper trigger design is optional.

Runs locally in your browser. No account, no backend, no server submission. The report is generated on-device and exported only if you choose to save it.

Phase 1

State the claim

One claim is enough. The goal is to get to a useful recommendation quickly, not to document the whole world.

Examples: Customers want Feature X. This architecture will scale. This release is production-ready.

Do you need to act on this now?

Phase 2

Show why the claim matters

This is the value of Clarity: what supports the claim, what is assumed, how exposed you are if it is wrong, and who owns the consequences.

How confident are you relative to the current evidence?

Confidence check

If this claim is wrong, how hard is recovery?
Why this exists: If recovery is hard, you need stronger justification before committing.

This can be new evidence, a missed outcome, a user signal, or something that would make the claim no longer hold.
