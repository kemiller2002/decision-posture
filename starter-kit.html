Quick Assessment Template

Use this when you want the Clarity quick-assessment structure without the interactive browser workflow. It is designed for one claim, one owner, one monitoring model, and one practical recommendation.

The interactive assessment and this template now use the same framework fields, so teams can move between them without changing the underlying model.

How To Use It

1. Pick one claim.

2. Assign a posture.

3. List the evidence.

4. Surface assumptions.

5. Check confidence against the current evidence.

6. Assess correctability before extending commitment.

7. Name the owner, signal, threshold, and trigger claim.

8. Define the immediate response and the reassessment trigger.

9. Decide how you would reassess the trigger itself.

10. Let the recommendation follow from the reasoning, not the other way around.

Why Split Triggers

A trigger is a predefined condition that prevents teams from continuing blindly when reality changes.

Some triggers exist to force immediate action. Others exist to force reassessment. Both support adaptation.

Both are based on claims about what a signal means, so both should be revisited when reality shows the threshold is poorly calibrated.
